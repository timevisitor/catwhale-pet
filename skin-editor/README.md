# 猫鲸皮肤编辑器（独立版 · 本地实装）

给「猫鲸桌宠」做皮肤的外挂工具：**上传/替换动作视频、给动作命名、指定触发逻辑、自由调大小与比例**，
保存后桌宠 2~3 秒内自动换装，不用重启桌宠（首次需重启一次以载入新版本桌宠程序）。

它**独立于桌宠主程序**：一个单独的窗口程序，只通过文件交换数据
（`%APPDATA%\桌宠\skins\<皮肤>\skin.json` + `videos\*.webm` + `active.json`），
卸载它不影响桌宠，删掉皮肤就回到内置素材。

---

## 一、怎么跑

**双击 `启动编辑器.bat`**（不需要安装任何东西，用桌宠自带的 Electron 运行时）。
想双击出 exe 版见文末「打包成独立 exe」。

界面三栏：

| 区域 | 用途 |
|---|---|
| 左栏 | 动作列表（点选编辑）。顶部「＋ 导入动作」= 用你自己拍/做的视频新建一个动作；底部「从内置添加」= 把内置动作复制一份来改 |
| 中间 | 预览画布：按桌宠真实比例（宽 = 高 × 0.6）播放当前动作，实时反映缩放/比例/位移；青虚线是脚底基线（96.67%） |
| 右栏 | 当前动作的属性：名称、触发逻辑、播放模式、速率、权重、整体缩放、宽/高比例、水平/垂直位移、视频信息 |

顶栏：皮肤下拉（可切内置皮肤只读对照）、新建 / 复制 / 删除皮肤、**保存**（Ctrl+S）、
**应用到桌宠**（= 保存 + 写 active.json，桌宠自动刷新）、启动桌宠。

---

## 二、第一次用

1. 双击 `启动编辑器.bat`。
2. 顶栏「新建」→ 填名称 → 起始内容选 **「完整复制内置皮肤」**（复制 11+1 个动作，约 18MB，几秒）→ 创建。
3. 左栏点一个动作，右栏改「整体缩放 / 宽比例 / 高比例 / 位移」，中间能立刻看到效果。
4. 点「应用到桌宠」。桌宠 2~3 秒内刷新；**如果没反应，说明桌宠还是旧版本，需要重启一次桌宠**（见第五节）。

---

## 三、导入自己的动作视频

点「＋ 导入动作」→ 选视频，然后填：

- **动作名称**：随便起，只影响列表显示。
- **触发逻辑**（决定这个动作什么时候出现，见下表）。
- **目标清晰度**：像素宽，默认 576（= 内置素材的宽度）。越小越省 CPU（VP9 透明视频只能软解）。
- **抠像颜色 / 容差**：源视频**没有**透明通道时才出现，默认自动取左上角像素颜色。
  猫鲸的原始素材是纯绿背景（约 `#10e613`），默认值就能抠干净；容差调大 → 抠得更狠（边缘更硬），
  调小 → 保留更多半透明边缘（可能残留绿边）。

转码走 ffmpeg → **VP9 + alpha 的 webm**（和内置素材同一规格），并自动写入时长/尺寸。
带透明通道的源（webm/mov/png 序列）只转码不抠像。

### 触发逻辑对照表

| 触发逻辑 | 桌宠里的行为 | 可否多个 |
|---|---|---|
| 空闲随机 · 循环 | 闲置 12 秒后，每隔 7~14 秒在同类动作里按权重挑一个循环播放 | 可以（按权重） |
| 空闲小动作 · 播一次 | 空闲时按 35% 概率触发一次，播完自动回待机 | 可以（按权重） |
| 点击互动 · 播一次 | 单击桌宠时随机播一次（不进空闲池） | 可以（按权重） |
| 干活中（长任务） | 桌宠里 DeepSeek 处理长任务时；空闲时也会以 0.6 倍权重被抽到 | 可以 |
| 待机（默认） | 没做任何事时的默认动作 | **只能一个** |
| 打开菜单时 | 打开 SAO 菜单/搜索/聊天/设置时 | 只能替换视频 |
| 拖动中 | 按住角色拖动时 | 只能替换视频 |
| 松手落下 · 播一次 | 松手后播一次，播完回待机 | 只能替换视频 |

> 为什么后四种只能「替换视频」：桌宠主程序是按固定 id（`idle` / `stand_arms` / `grabbed` / `drop`）直接调用这几个状态的，
> 改名就调用不到了。所以这四类动作在列表里标为「核心动作」——可以换视频、可以调大小，不能改名/删除。

---

## 四、大小与比例怎么算

- **整体缩放**：以**脚底基线**为基准放大缩小（放大人不离地），和桌宠设置里的大小滑块是两个独立倍率，会相乘。
- **宽比例 / 高比例**：在整体缩放之上再单独拉宽/压扁（勾「锁定比例」两者同步）。
- **水平/垂直位移**：按画布的百分比平移（画布 = 桌宠高度 × 0.6 宽）。
- 「套用到全部」：把当前动作的这四组参数复制给皮肤里所有动作（做整体尺寸统一时用）。

这些都写进 `skin.json`，桌宠读同一套语义（`scale` / `scaleX` / `scaleY` / `offX` / `offY`）。

### 预览画布上的三条参考线

底部「参考线」勾选控制，颜色含义：

| 颜色 | 线 | 含义 |
|---|---|---|
| 青 | 脚底基线 96.7% | 桌宠的缩放原点（`transform-origin: 50% 96.67%`），所有缩放绕它进行，所以放大人不离地 |
| 橙 | 标准身高 | **当前皮肤「待机」动作的实测头顶位置**（换皮肤会跟着变）。这是判断"别的动作比标准高/矮多少"的基准 |
| 紫 | 当前动作头顶 | 当前选中动作的实测头顶，**跟着缩放/比例/位移实时移动**，标签上直接写"比标准高/矮多少个百分点" |

两条线都是**真量出来的**，不是估的：主进程用 ffmpeg（VP9 必须走 `libvpx-vp9` 解码器，原生解码器不出 alpha）
一次抽 5 帧 96px 宽的 rgba 原始帧，取每帧 alpha>32 的最上一行，再取 5 帧中位数，
最后按 `object-fit: contain` 的留边和该动作的 transform 换算成画布百分比。

右栏「视频」分组里的**内容高度**一行给的是同一组数字（实测头顶 / 实测脚底 / 占画布高多少）。
坐姿、腾空、跳高类天然比站姿标准矮，属于正常，不是素材错了。

## 五、生效 / 回退

- **生效**：编辑器「应用到桌宠」写 `%APPDATA%\桌宠\skins\active.json`，桌宠每 2.5 秒比对
  `skin.json` 的修改时间，变了就重载页面（位置、聊天记录都保留）。
- **首次安装本功能后要重启一次桌宠**：正在运行的旧版桌宠没有读皮肤的代码。重启方式：
  托盘右键退出 → 再启动，或双击 `重启桌宠.bat`。
- **回退到内置素材**：编辑器里点「删除」删掉皮肤，或直接删 `%APPDATA%\桌宠\skins\active.json`，
  桌宠 2.5 秒内自己回到内置素材。内置素材本身**从未被改动**。

## 六、皮肤包格式（想手改也看得懂）

```
%APPDATA%\桌宠\skins\
  active.json                 {"slug":"my-catwhale"}
  my-catwhale\
    skin.json                 { format, id, name, updated, actions: { <动作id>: {...} } }
    videos\idle.webm ...
```

单个动作：

```json
{
  "id": "tail_open", "name": "睁眼摇尾", "file": "videos/tail_open.webm",
  "mode": "loop", "role": "lounge",
  "scale": 1.0, "scaleX": 1.0, "scaleY": 1.0, "offX": 0, "offY": 0,
  "rate": 1.0, "weight": 35, "react": 40, "duration": 4.042
}
```

`role` 取值：`idle` `lounge` `idle_act` `interact` `task` `menu` `drag` `release`；
`weight` 用于空闲池，`react` 用于点击池，`rate` 是该动作自带播放速率（与界面速度滑块相乘）。

## 七、验收记录（都是真跑出来的）

- `verify/host/`：**验收宿主**。用桌宠真实的 `app/renderer` + `app/preload.js`，
  复刻主进程的静态服务与 `/skin/` 路由，跑一遍皮肤加载并**逐项数值核对** transform
  （不靠肉眼，也不读页面内部变量）。结果见 `verify/out/report.json`：
  12 个动作全部走 `/skin/`、`readyState` 就绪、`scaleX/scaleY/translate` 与 `skin.json` 一致、active 唯一。
- `verify/out/uitest.json`：编辑器 UI 全流程真点击（新建皮肤 → 复制 12 个内置动作 → 改缩放/位移 →
  保存 → 应用到桌宠 → 核对磁盘产物 12 个 webm，18MB）。
- `verify/out/ui-*.png`：上述流程截图。

复跑：

```bash
# 在仓库根目录执行；ELECTRON 指向桌宠自带的运行时
ELECTRON="app/node_modules/electron/dist/electron.exe"

# 编辑器 UI 全流程（会真的建一个 uitest_skin 皮肤，跑完请在编辑器里删掉）
"$ELECTRON" skin-editor --uitest

# 皮肤渲染验收（不启动完整桌宠，不受单实例锁影响）
"$ELECTRON" skin-editor/verify/host \
  --skin="$APPDATA/桌宠/skins/my-catwhale" --out="skin-editor/verify/out"
```

## 八、桌宠侧改了什么（就 3 个文件）

| 文件 | 改动 |
|---|---|
| `web/index.html` | 启动时向主进程取当前皮肤并合并到内置 `states`；视频源支持 `/skin/`；`transform` 支持 `scaleX/scaleY/offX/offY`；空闲小动作改为按权重抽取 |
| `app/main.js` | 新增 `SKIN_ROOT` / `/skin/` 静态路由 / `skin:get`、`skin:openFolder` IPC / 皮肤文件变更自动重载；`--diag` 多输出视频完整 URL 与 transform |
| `app/preload.js` | 暴露 `petHost.skin.get / openFolder` |

没有皮肤时行为与改动前完全一致（`active.json` 不存在 → 直接用内置 `states.json`）。

## 九、已知限制

- 动作时长/帧率由视频本身决定，编辑器不裁剪；一次性动作（`once`）的停留时长取视频时长 ÷ 速率。
- 一次只能导入一个动作；同名动作视频会被覆盖（参数保留）。
- 视频清晰度上限 1200px 宽；VP9 透明视频只能软解，宽度越大越吃 CPU（内置素材是 576×960）。
- 核心动作（待机/菜单/拖动/松手）不能改名、不能删，只能替换视频。
